# Flat Out

Flat Out is a small Australian-themed endless runner game built with Python and pygame-ce.

Inspired by the Chrome Dinosaur game, the player runs through an Australian environment and avoids wildlife obstacles while trying to survive for as long as possible.

This project is being built as a first independent portfolio project while completing the Boot.dev Backend Developer Path.

## Goals

- Build a complete project independently rather than following a tutorial.
- Improve Python and pygame skills.
- Practise structuring, testing and reviewing a small project.
- Use Git and GitHub throughout development.
- Deploy the game so it can be played in a web browser.
- Keep the project within approximately 20–40 hours.

## Tech Stack

- Python
- pygame-ce
- pygbag
- Git / GitHub

## MVP

The first playable version will include:

- Player jumping
- Ground collision
- Snake obstacle
- Player/obstacle collision
- Game over and restart
- Score based on survival/distance
- Increasing difficulty
- Browser-playable build

## Possible Extra Features

If time allows:

- Emu obstacle
- Swooping magpie obstacle
- Other Australian wildlife
- Sound effects
- Improved graphics and animations
- Local high score

## Out of Scope

To keep the project small and achievable, the initial version will not include:

- User accounts
- Online multiplayer
- Online leaderboard
- Backend API
- Multiple levels

## Milestones

### 1. Technical Spike
- Create a pygame window.
- Draw a basic player and ground.
- Implement jumping.
- Confirm the project runs in a browser using pygbag.

### 2. Core Game
- Add the snake obstacle.
- Add collision detection.
- Add game-over and restart behaviour.
- Add scoring.

### 3. Gameplay and Polish
- Increase difficulty over time.
- Add additional obstacles if time allows.
- Improve visuals and sound.
- Fix bugs and improve game feel.

### 4. Release
- Test the browser build.
- Deploy the game.
- Finalise the README.
